Upload your resume, describe the role, and Hiretrack generates grounded interview questions from your actual experience — then evaluates every answer in real time using Groq's Llama 3.3 model.

## What Hiretrack Does

Hiretrack walks candidates through a complete mock interview lifecycle — from resume parsing to final scored report — all powered by AI.

<Steps>
  <Step title="Upload your resume">
    Hiretrack extracts text from your PDF or DOCX resume, parses it with Groq into structured skills, experience, and projects, and stores it in Cloudinary.
  </Step>
  <Step title="Configure an interview">
    Select a job role, paste a job description, choose your experience level (entry through executive), and pick how many questions you want (3–20).
  </Step>
  <Step title="Answer questions in real time">
    Questions are generated by a RAG pipeline that grounds every question in your actual resume and the job description. Submit answers and receive streaming AI follow-ups via Socket.io.
  </Step>
  <Step title="Review your report">
    After completing the session, Hiretrack generates a detailed report: per-answer scores (1–10), an overall score (1–100), key strengths, weaknesses, and an improvement plan.
  </Step>
</Steps>

## Tech Stack

Hiretrack is built on the MERN stack with several AI and real-time integrations:

| Layer | Technology |
|---|---|
| Backend | Node.js + Express |
| Database | MongoDB (Mongoose) |
| AI / LLM | Groq SDK — Llama 3.3 70B |
| Embeddings | OpenAI `text-embedding-3-small` via LangChain |
| Real-time | Socket.io |
| File storage | Cloudinary + Multer |
| Caching | Redis (ioredis) |
| Job search | Adzuna API |
| Frontend | React 18 + Vite + Tailwind CSS |
| Auth | JWT (access + refresh tokens) |
